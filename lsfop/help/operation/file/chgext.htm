拡張子の一括変更

指定の場所に存在する特定の拡張子を持つファイルを、新しい拡張子で名前を変更します。 例えば、対象拡張子を“txt”、新しい拡張子を“tmp”と指定して実行すれば、拡張子“txt”を持つファイルはすべて、 拡張子 “tmp” に置きかえられます。

現在のフォルダを先頭に、そのフォルダ配下の階層にあるフォルダを対象として、 一括して拡張子名を変更することも可能です。

  1. 変更をおこなうファイルが存在するフォルダを指定します。
  2. 対象となる拡張子を入力します。拡張子の先頭の“．”（ドット）は必要ありません。
  3. 新しい拡張子を入力します。
  4. 1.で指定したフォルダに子フォルダがある場合、その子フォルダ配下のファイルも対象とするか指定します。
