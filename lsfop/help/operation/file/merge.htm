ファイルの連結

指定ファイルを他のファイルへ連結コピーします。 連結する順序や、追加連結などのオプション機能もあります。

連結して作成するファイル名

選択したファイルを連結してまとめるファイル名を指定します。
既存のファイルを指定した場合には、その既存ファイルへ連結されます。

EOFを取り除いて連結する

テキストファイルの場合、ファイルの最後には通常[EOF]コード(0x1A)が存在しています。 これをそのまま残しながら連結させると、使用するテキストエディタによっては、 連結したファイルの途中にあるこの[EOF]をファイルの終端として認識してしまうものもあります。 これらの問題を回避するには、このオプションをチェックします。

連結して追加するファイルを、その都度その場で指定する

分割したファイルを複数のフロッピーディスクなどに分散させている場合には、 連結するファイル群を列挙するのは面倒です。最初のファイルのみをリストして、 このオプションをチェックして実行すれば、リストされているファイルを処理した後、 次の継続して連結するファイルを指定するダイアログボックスが開きます。 連結作業を終了するには、このダイアログボックスでの選択をキャンセルします。
