FileVisor7 オンラインヘルプ

大文字小文字を置換する

ファイル名文字列の大文字小文字の文字変換をおこないます。

  • 全て大文字に変換する
    例） command.com から COMMAND.COM へ
  • 全て小文字に変換する
    例） COMMAND.COM から command.com へ
  • 先頭文字のみ大文字に変換する
    例）COMMAND.COM から Command.com へ

設定補助項目

  • 拡張子のみに適用する
    拡張子のみを変換の対象とします。
  • サブフォルダ内のファイルも対象とする
    配下のサブフォルダ内の全てのファイルも対象とします。
  • フォルダ名には適用しない
    フォルダ名は変換しないようにします。
