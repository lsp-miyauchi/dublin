制限事項

対象のオペレーティングシステム

以下のオペレーティングシステム（64bit、32bit）で利用可能です。 記載外のオペレーティングシステムはサポート対象外です。

  • Windows 10, 8.1, 8, 7, VISTA
  • Windows Server 2012R2, 2012, 2008 R2, 2008

　

ご購入前試用時の制限事項

  • 起動時に試用開始キーの入力が必要な場合があります。
  • 長時間連続して試用している場合、最小化時に（常駐設定でも）自動終了する場合があります。
  • コピー・移動などの処理の開始時に、FileVisorのアプリケーション情報が表示される場合があります。
