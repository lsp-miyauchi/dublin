コピー・移動

選択されているファイル・フォルダをコピーします。フォルダをコピーする場合には、そのフォルダ階層下のすべてのフォルダおよびファイルを階層状態のままコピーすることができます。

このコマンドを実行すると、相手先パス名を入力するダイアログボックスが開きます。相手先パス名は、直前の操作から遡ってのヒストリを記憶していますから、 前回以前に指定したパス名をドロップダウンリストから選択できます。 また、しおりパネルで登録したフォルダを参照したり、ドライブを指定して フォルダを参照したりすることも可能です。

管理者として実行する

Windows VISTA以降のオペレーティングシステムを利用している場合、 特定のドライブ・フォルダにはシステムのセキュリティ制限があり、 コピー・移動などのファイル操作がおこなえません。
そのような場合にこのオプションを利用することで、アクセス権限を確保して ファイルのコピー・移動などが可能になります。

並行して実行

コピー・移動の処理がバックグラウンド（FileVisor本体とは異なる別プロセス） として実行されます。

処理完了後に相手先フォルダをタブで開く

コピー・移動が完了した後、相手先のフォルダを新しいタブで開きます。 （※並行して実行時には無効です）

ネットワークパスを指定する

ネットワーク先のフォルダをコピー先に指定することができます。 このネットワークパスはローカルドライブにアサインされていなくても UNC名で指定すれば直接コピー操作が可能です。 こういったパスをしおりパネルに登録しておけば、 以下のダイアログボックスから呼び出すことも可能になり、さらに使いやすくなります。
