書庫ファイルの正当性検査

選択された書庫（LZH/ZIP/CAB）ファイルの正当性を検査します。
複数の書庫を連続して検査できます。

「書庫ファイルの正当性検査」を選択すると、 選択された書庫ファイルが列挙されたダイアログボックスウィンドウが表示されます。 ここで「開始」を実行すると列挙された書庫ファイルを順次検査して、その結果をアイコン表示します。
異常が発見された場合には結果一覧の該当書庫ファイルをマウスでダブルクリックすることにより、 異常の原因が表示されます。

なお、取り外し可能メディアへ書庫ファイルをコピーした直後にメディア上のファイルを検査する場合には、 一旦メディアを取り出してから再挿入して検査することをお勧めします。 これは、メディアへのコピーの際にキャッシュが働くと、検査すべきファイルがメディアから読み込まれるのではなく、 キャッシュ上のデータが読み込まれる可能性があるからです。

結果情報のアイコンの意味

...　問題はありません。
...　異常が見つかりました。書庫が破損しています。
...　検査できません。検査可能な書庫ファイルではありません。
...　現在検査しています...
